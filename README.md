# مَقطع — برنامج مونتاج الفيديو

برنامج شخصي لجمع المقاطع والصور في فيديو واحد مع الموسيقى والكتابة والملصقات. بديل بسيط لـ VivaVideo القديم.

- **الرابط:** https://shaari01.github.io/mashhad/
- تطبيق ويب قابل للتثبيت (PWA)، يعمل بلا إنترنت بعد أول فتح.
- واجهة عربية من اليمين إلى اليسار، وأيقونات كبيرة للمس.
- مصمَّم لجوالات وتابلت سامسونج (Chrome)، ولابتوب ويندوز 10 (Chrome أو Edge).

## التثبيت
- **أندرويد:** افتح الرابط في Chrome ← القائمة ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- **ويندوز:** افتح الرابط في Chrome أو Edge ← أيقونة التثبيت في شريط العنوان.

## للمطوّر
```bash
npm ci
npm run dev        # خادم التطوير
npm test           # اختبارات الوحدات
npm run build && npm run test:e2e   # اختبارات المتصفح (تحتاج Playwright وChromium وffmpeg)
```

راجع [PROGRESS.md](PROGRESS.md) لما أُنجز في كل مرحلة، و[DECISIONS.md](DECISIONS.md) للقرارات التقنية وأسبابها.
